# 100-Days-of-python-bootcamp
"Mastering Python for Robotics &amp; Automation. 100 days of consistent coding projects, moving from fundamentals to advanced systems. Engineering a solid foundation, one day at a time. 🚀"
## 📂 Repository Structure

Each day is organized into a dedicated folder to keep things clean and easy to navigate:

* **`Exercises.py`**: Contains all the daily practice examples and mini-challenges. 
    > **Note:** To run a specific example, simply copy and paste the relevant code block into your IDE.
* **`project.py`**: The final daily capstone project—this is where I apply everything I learned during the day to solve a real-world task.
